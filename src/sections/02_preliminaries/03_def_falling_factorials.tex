We use the following notation for falling factorials.
\begin{definition}[Falling Factorials]
  \label{def:falling-factorials}
  For integers $n$ and $k$, define the falling factorial by
  \begin{align*}
    \fallingFactorial{n}{k} =
    \begin{cases}
      0, \quad & \mathrm{if \; } k < 0, \\
      1, \quad & \mathrm{if \; } k = 0, \\
      \prod_{j=0}^{k-1} (n-j), \quad & \mathrm{if \; } k>0.
    \end{cases}
  \end{align*}
\end{definition}
For further discussion of generalized factorials, see J. F. Steffensen~\cite{steffensen1933definition}.
