======================================================== NAME =====================================================

Triangle read by rows: T(n,k) = Sum_{j=0..k} (-1)^j * binomial(k,j) * (4-j)^n.

======================================================== DATA =====================================================

======================================================== FORMULA =====================================================

T(n,k) = Sum_{j=k..n} binomial(4-k, j-k) * Stirling2(n, j) * j!.
T(n,k) = Sum_{j=0..n} E(n,j) * binomial(4+j-k, n-k), where E(n,j) are Eulerian numbers (Cf. A173018).
Let F(t, n, k) = Sum_{j=0..k} (-1)^j * binomial(k,j) * (t-j)^n,
then
F(0, n, k) = A278075(n,k),
F(1, n, k) = A389570(n,k),
F(2, n, k) = A391068(n,k),
F(3, n, k) = A391210(n,k),
F(4, n, k) = T(n,k) (this sequence).
Let S_m(n) be a sum of powers: S_m(n) = 1^m + 2^m + 3^m + ... + n^m, then
S_m(n) = Sum_{j=0..m} T(m,j) * ( (-1)^j*binomial(4,j+1) + binomial(n+j-4,j+1) ).

======================================================== MATHEMATICA =====================================================

(*Prints T(n,k) as triangle*)
T1[t_,n_, k_] := Sum[(-1)^j*Binomial[k, j]*(t - j)^n, {j, 0, k}];Table[T1[4, n, k], {n, 0, 10}, {k, 0, n}] // Flatten
(*Validates T(n,k) in Stirling form*)
T2[t_, n_, k_] := Sum[Binomial[t - k, j - k]*StirlingS2[n, j]*j!, {j, k, n}];Table[T2[4, n, k], {n, 0, 10}, {k, 0, n}] // Flatten
(*Validates T(n,k) in Eulerian form*)
Eulerian[n_, k_] := Sum[(-1)^s*Binomial[n + 1, s]*(k + 1 - s)^n, {s, 0, k}];
T3[t_, n_, k_] := Sum[Eulerian[n, j]*Binomial[t + j - k, n - k], {j, 0, n}];Table[T3[4, n, k], {n, 0, 10}, {k, 0, n}] // Flatten
